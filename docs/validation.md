# 验证记录

## 自动化检查

测试覆盖：

- 提单格式标准化、去重、错误输入隔离。
- API 鉴权、用户隔离、证据权限；拒绝任意 prompt 等额外输入。
- 幂等提交、持久化重启回读、队列容量与请求限流。
- 多数据库连接领取互斥、全局/同航司并发限制。
- 过期租约恢复、旧 Worker 不能覆盖新尝试。
- 取消优先于晚到结果、手动重试不能重复排队。
- 临时失败延后重试，其他航司继续执行。
- 同票/同航段/来源/quote/实际标签/时间字段验证。
- 时间冲突、拆批、公路航段、明确无记录与访问受阻的区分。
- 证据正文摘要、签名、JSON 字段重排和跨尝试重放。
- 浏览器公网域名约束、私网及云元数据地址拒绝。
- CLI 固定配置、有限工具预授权、敏感环境不继承、超时结束进程和临时文件清理。

运行：`npm run check`。测试中的航班时间为明确虚构的固定夹具，不作为线上结果来源。

本地 `npm run check` 通过：19 项自动化测试、TypeScript 检查和生产构建。

真实查询使用已授权网关、Codex CLI 和项目自带的独立浏览器，不依赖 Codex 桌面端浏览器。验证过程的真实原文、截图、模型凭证和运行数据库不提交仓库。
